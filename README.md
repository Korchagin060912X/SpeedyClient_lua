# Speedy Client

Набор клиентских скриптов и интерфейсов для **Roblox**. Проект написан на **Luau** — языке Roblox, основанном на Lua и расширенном для работы с Roblox API.

> **Важно:** скрипты предназначены для Roblox и конкретных игр, перечисленных ниже. FPS Boost изменяет только локальное отображение и настройки производительности. Поддержка разблокировки FPS зависит от доступности `setfpscap` в клиентской среде. Roblox не предоставляет обычному клиентскому скрипту API для сжатия произвольных изображений интерфейса.

## Игры и файлы

| Игра / раздел | Файл | Назначение |
|---|---|---|
| **DOORS** | [`Doors_Scripts/Main.client.lua`](./Doors_Scripts/Main.client.lua) | Клиентский скрипт с игровыми функциями, настройками интерфейса и уведомлениями для DOORS. Использует UI-библиотеки Linoria/Obsidian и ESP-модуль. |
| **Murder Mystery 2 (MM2)** | [`MM2_Scripts/Main.client.lua`](./MM2_Scripts/Main.client.lua) | Основной клиентский скрипт с меню, настройками и игровыми функциями, включая AutoFarm монет и Anti-AFK. |
| **Murder Mystery 2 (MM2)** | [`MM2_Scripts/Safe.client.lua`](./MM2_Scripts/Safe.client.lua) | Облегчённый вариант с меню Speedy Client, переключением разделов и настройкой клавиши меню. |
| **Roblox — FPS Boost** | [`Utilities_Scripts/FPSBoost.client.lua`](./Utilities_Scripts/FPSBoost.client.lua) | Перетаскиваемый FPS Viewer, FPS Unlocker при поддержке среды, минимальное качество графики Roblox, локальное упрощение материалов и скрытие 3D-объектов. |

## На чём и как сделано

- **Язык:** Luau — диалект Lua для Roblox.
- **Платформа:** клиентская среда Roblox; файлы `.client.lua` рассчитаны на запуск как клиентские скрипты.
- **Интерфейс:** создаётся средствами Roblox UI (`ScreenGui`, `Frame`, кнопки и другие элементы).
- **Анимации и ввод:** для анимаций используется `TweenService`, для клавиш и управления — сервисы Roblox.
- **DOORS:** UI-библиотека и ESP-модуль загружаются скриптом во время выполнения.
- **FPS Boost:** настройки применяются локально и восстанавливаются при выключении функций или выгрузке меню. Изменение качества графики не может сжать изображения чужих меню: Roblox не предоставляет клиентскому скрипту API для изменения разрешения произвольных image assets.
- **FPS Unlocker:** требует `setfpscap` в клиентской среде. Фактическая частота кадров также ограничена устройством и частотой обновления его экрана.
- **Disable 3D Rendering:** если клиент не предоставляет переключатель 3D-рендеринга, скрипт локально скрывает 3D-объекты и эффекты; интерфейс остаётся видимым.
